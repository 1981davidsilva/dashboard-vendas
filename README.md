# 📊 Dashboard de Vendas

Dashboard interativo desenvolvido em Excel para análise comercial e acompanhamento de indicadores de desempenho.

---

## 🎯 Objetivo do Projeto
Apresentar indicadores estratégicos de vendas de forma visual e intuitiva, auxiliando na tomada de decisão comercial.

---

## 📌 Indicadores Apresentados
- Total em vendas
- Valor de descontos 
- Média de descontos
- Vendas por vendedor
- Vendas por região
- Vendas por categoria
- Evolução mensal das vendas

---

## 🛠 Ferramentas Utilizadas
- Microsoft Excel
- Tabelas Dinâmicas
- Gráficos Dinâmicos
- Segmentação de Dados
- Dashboard Interativo
